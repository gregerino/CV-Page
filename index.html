AI tool · Recruitment

Recruitment OS

Turns a requirements profile into a structured interview package, so two managers recruiting for the same role assess the same things.

An AI tool that turns a requirements profile into an interview package with competency analysis, 15–20 structured questions with follow-ups, scorecards and support for reducing bias. It also has a competency library with level indicators and personality competencies based on Big Five, so that two managers recruiting for the same role assess the same things.

AI agents · Recruitment

An agentic operating system for recruitment

Agents do the groundwork, such as a first CV assessment, and hand the decision to the recruiter.

Agents in the background do the groundwork, for example a first CV assessment when an application comes in. Then they create a task for the recruiter, who makes the decision. The assessment builds on Recruitment OS: the agent marks evidence in the CV for each competency, and the recruiter scores each one from 1 to 5 with a written motivation. Interview assessments stay in the recruitment system. Other agents find candidates and book interviews, and only the one that books may act without approval. In a visual cockpit the recruiter sees what the agents have done and what's waiting, and the system reminds them of feedback that needs to go out.
